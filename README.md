# experta.tech

Персональный сайт Ильи Носкова: AI-инженера, архитектора ИТ-решений, бизнес-аналитика и интегратора.

## Локальный запуск

Сайт статический. Откройте `index.html` напрямую или запустите локальный HTTP-сервер:

```powershell
python -m http.server 8080
```

После этого сайт будет доступен по адресу `http://localhost:8080`.

## Структура

- `index.html` — главная и основные практики;
- `stack.html` — технологический стек;
- `certificates.html` — сертификаты и документы;
- `partners.html` — друзья и партнёры;
- `assets/` — стили, сценарии и изображения.

Сертификаты и документы добавляются по мере подготовки материалов.

## Размещение: собственный сервер, обновления через GitHub

- Репозиторий: `CAB24/experta-tech`, ветка `main`.
- Сервер: `79.174.90.25`. GitHub используется для хранения исходников; GitHub Pages не является целевым хостингом.
- Основной адрес: `https://experta.tech/`.
- Обращения по HTTP и старому IP перенаправляются на HTTPS-домен с сохранением пути и параметров.
- Caddy обслуживает `/srv/experta-tech/current`; выпуск и продление HTTPS-сертификата выполняются автоматически.
- `experta-deploy.timer` раз в минуту получает изменения из GitHub. Выкладка выполняется отдельным пользователем `experta-deploy`: новый релиз проверяется, затем ссылка `current` переключается атомарно. Предыдущий релиз доступен по ссылке `previous`.
- В публикацию входят только HTML, `assets`, `robots.txt`, `sitemap.xml`. Код деплоя и метаданные Git недоступны через сайт.

Файлы установки находятся в `deploy/`. Перед первичной установкой настройте DNS домена на сервер и дождитесь его обновления. Установка на сервере из этой папки: `sudo bash install-server.sh`. Проверка после установки обращается к HTTPS-домену и проверяет сертификат. Последующие изменения скриптов деплоя требуют повторной установки администратором; сервер не выполняет скрипты, полученные из репозитория.

Проверка на сервере:

```sh
systemctl status experta-deploy.timer
journalctl -u experta-deploy.service -n 30 --no-pager
cat /srv/experta-tech/deployed-commit
```

DNS: A-запись `experta.tech` должна указывать на `79.174.90.25`. IP GitHub Pages использовать не нужно. Почтовые MX/TXT и записи других поддоменов сохраняются.
